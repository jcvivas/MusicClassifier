# MusicClassifier

Aplicación web simple para clasificar archivos de audio. Esta versión contiene únicamente el cliente de la aplicación, mostrando cómo será la interfaz sin integrar todavía un modelo de inteligencia artificial.

## Uso

1. Abre `index.html` en tu navegador.
2. Selecciona un archivo de audio y pulsa **Clasificar**.
3. Se mostrará un resultado simulado mientras se construye el modelo real.

El diseño está pensado para ser extendido en el futuro con un backend y un modelo de clasificación de música.
